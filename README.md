# Trip photos

The 9 trips use real photographs from Wikimedia Commons, loaded from the web addresses in `script.js` (internet needed). To make them work offline, open `save-photos.html` with internet on, click **Download all**, and move the files into this `images` folder. The site uses files in this folder first.

`background.jpg` is the page and top-banner background.
